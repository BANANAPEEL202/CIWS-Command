# CIWS Command
Command an Arleigh Burke class destroyer and survive against waves of incoming missiles using your 2 Phalanx CIWS systems. Play in the browser [here](https://bananapeel202.github.io/CIWS-Command/)

Built in **Unity 6.0 LTS (6000.0.85f1)**.

## Controls

Use WASD or arrow keys to control the ship. Missile waves arrive from a random direction each time. Missile hits disable individual modules: offline CIWS mounts cannot shoot, lost engines drop the throttle to Stop so the ship coasts down (you can still steer), and an offline radar stops tracking.

Press **1** for the forward CIWS, **2** for the aft CIWS, **3** for engines, or **4** for radar to assign the repair crew, or click the module's key in the damage-control console at the bottom of the screen. Each repair takes **20 seconds** of gameplay time. Only one module repairs at a time; switching pauses the previous repair. With up to three modules down the ship can recover, but losing all four ends the game, even if one is mid-repair.
